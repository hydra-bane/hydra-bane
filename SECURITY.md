# Security policy

Hydra-bane moves and deletes files, so a guard bypass is a security bug.

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/hydra-bane/hydra-bane/security/advisories/new), not public issues. Useful reports include the command or plan that got past the path guard, the approval hook, or the quarantine checks, and the Windows and Node.js versions.

Only the latest release is supported.
